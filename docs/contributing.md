```
 ┃ ┣ config.py             Package-wide constants
 ┃ ┣ gifba_object.py       gifbaObject: the fixed-point giFBA simulation engine
 ┃ ┣ summary.py            CommunitySummary: post-run uptake/secretion reporting
 ┃ ┗ utils.py              Input validation, toy-model loader, minimal-medium search, MICOM/cFBA interop
 ┣ 📂tests
 ┃ ┣ conftest.py           Shared fixtures (toy_models, toy_community, run_toy), pinned to GLPK
 ┃ ┣ golden_values.py      Measured reference fluxes for the 10 toy models
 ┃ ┣ test_toy_models.py    End-to-end regression tests over the toy models
 ┃ ┣ test_summary.py       Tests for CommunitySummary
 ┃ ┗ test_validators.py    Tests for the utils.check_* input validators
 ┗ pyproject.toml          Package metadata, dependencies, optional extras
```

## Testing

Run from the repository root (the suite takes about 3 seconds):

```bash
python -m pytest package/tests               # full suite
python -m pytest package/tests -k validators  # solver-free subset
python -m pytest package/tests -x -q          # stop on first failure
```

CI (`.github/workflows/tests.yml`) runs the same suite on Python 3.10 and 3.13 with
GLPK on every push and pull request.

- `tests/conftest.py` pins the LP solver to GLPK. The golden values were measured
  under GLPK, and CI has no Gurobi license, so do not remove the pin.
- `tests/golden_values.py` holds measured reference fluxes for the ten toy models.
  Treat a change there as deliberate: re-measure rather than hand-edit, and explain
  in the commit message why the numbers moved.
- New tests should cover behaviour that works today. Known defects are tracked
  separately rather than encoded as `xfail`.

## Docstrings and autodoc

Public modules, classes and functions should have Google-style docstrings and static
type hints. Much of the source does not meet this yet, so the
[API Reference](api.md) is written by hand for now. Once the docstrings are in place,
that page will switch to `::: gifba...` blocks rendered by mkdocstrings, which is
already configured in `mkdocs.yml`.

## Building the docs

```bash
pip install mkdocs-material "mkdocstrings[python]"
mkdocs serve           # live preview at http://127.0.0.1:8000
mkdocs build --strict  # fail on broken links or missing pages
```

`.github/workflows/docs.yml` deploys the site to GitHub Pages on every push to `main`.

## AI usage

Parts of this repository — including portions of the code, tests, and this
documentation — were drafted & implemented with the assistance of AI coding tools (Claude Code).
All AI-assisted contributions are reviewed by the project maintainers, and the
underlying scientific method, model validation, and numerical results (e.g. unit 
testing) are checked against expected biological/mathematical behavior rather 
than taken on faith from generated output.
